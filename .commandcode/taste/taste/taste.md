- Wants the development journey tracked as an HTML artifact (not just markdown logs), starting from the initial build of the site and chaining later changes as explicit revisions. Confidence: 0.65
- Wants a project brief template handed over for the user to fill in before any project work starts, rather than being interrogated with questions first. Confidence: 0.75
